# Formula Finishes Showcase

Build a modern, premium, responsive website for Formula Finishes and Interiors. Access the Google Drive folder I provide. Extract products and images from the catalog. Create pages: Home, About, Products (categorized with filters), Services, Projects for completed installations, Gallery, Contact, and a sticky navigation bar with all those links. Use a premium interior design aesthetic. Modern typography, clean color palette, smooth scrolling, hover animations, responsive grids, and optimized images. Build with React, using reusable components and clean folder structure. If the Drive folder can't be accessed, ask the client to make it shareable or upload files directly. Deliver React-ready data files and components, so the site is production-ready with minimal manual editing.
